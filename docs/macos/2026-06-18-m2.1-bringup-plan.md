# Zodl macOS — M2.1 Bring-up Plan

> Bite-sized tasks. Each ends green (macOS scheme builds + iOS scheme builds) and, where it changes code, a commit. Checkboxes track progress.

**Goal:** A separate native macOS target (`Zodl-macOS`) that **builds, launches, and syncs via Slipstream** — every UIKit blocker `#if os(iOS)`-gated or stubbed.

**Architecture:** Separate SwiftUI target sharing the TCA/SwiftUI feature code; iOS-only files & Dependency Live keys gated behind `#if os(iOS)` with macOS stubs/siblings.

**Tech:** Swift · SwiftUI · TCA · ZcashLightClientKit (slipstream) · minimal AppKit.

**Legend:** 🖱️ = Xcode UI (you) · ⌨️ = code edit (agent). Build command used throughout:
`xcodebuild -scheme Zodl-macOS -destination 'platform=macOS,arch=arm64' build`

---

### Task 1 🖱️ — Link the SDK to the macOS target

### Task 2 ⌨️ — Inventory the macOS compile blockers
- [ ] Add the shared feature sources to `Zodl-macOS` target membership (🖱️ if the synchronized group needs it)

### Task 3 ⌨️ — Gate iOS-only files
- [ ] Wrap the contents of each in `#if os(iOS) … #endif`: `AppDelegate.swift`, `ScanUIView.swift`, `QRCodeScanView.swift`, `UIShareDialog.swift`, `UIMailDialog.swift`, plus any file surfaced in Task 2 that hard-imports UIKit.
- [ ] **Verify:** those files no longer error on the macOS build.
- [ ] **Commit:** `[#1755] slipstream: macOS — gate iOS-only files behind #if os(iOS)`

### Task 4 ⌨️ — Gate / stub iOS-only Dependency Live keys
- [ ] For each of `BackgroundTaskClientLiveKey`, `PasteboardLiveKey`, `FeedbackGeneratorLiveKey`, `LocalAuthenticationLiveKey` (+ any share/mail client): `#if os(iOS)` the UIKit impl and add a `#if os(macOS)` sibling —
  - Pasteboard → real `NSPasteboard`
  - Haptics → no-op
  - Background task → no-op (sync-while-open)
  - Biometrics → minimal `LAContext` or stub (real in M2.3)
  - Share / mail → stub returning gracefully (real in M2.3)
- [ ] **Verify:** the Dependencies layer compiles on macOS.
- [ ] **Commit:** `[#1755] slipstream: macOS — macOS Dependency siblings/stubs`
